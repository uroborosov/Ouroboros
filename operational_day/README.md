# Система «Операционный День»

Эта система предназначена для анализа операционной деятельности, включая производительность сотрудников, эффективность процессов и входящий поток документов.

## Функциональность

- Загрузка данных из CSV-файлов
- Анализ производительности сотрудников
- Анализ эффективности процессов
- Анализ входящего потока документов
- Анализ структуры персонала
- Генерация отчета в формате Markdown

## Требования

- Python 3.7+
- pandas
- python-dateutil

## Установка

1. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование

Запустите основной скрипт:
```
python main.py
```

Скрипт автоматически:
1. Загрузит данные из папки `../data`
2. Выполнит анализ
3. Сгенерирует отчет в формате Markdown в папке `reports`

## Структура проекта

```
operational_day/
├── main.py            # Основной скрипт анализа
├── requirements.txt   # Зависимости
├── README.md          # Документация
├── data/              # Директория для данных (создается при необходимости)
└── reports/           # Директория для отчетов (создается при необходимости)
```

## Пример отчета

Сгенерированный отчет будет содержать следующие разделы:
- Анализ производительности сотрудников
- Анализ эффективности процессов
- Анализ входящего потока документов
- Анализ структуры персонала

Отчет сохраняется в папке `reports` с временной меткой в названии файла.
